# Sistema de Controle de Despesas Pessoais

## Sobre o projeto:

Este projeto trata-se do desenvolvimento de uma aplicação web para registrar, consultar, editar e excluir despesas pessoais, permitindo organizar os gastos por categoria e consultar os gastos totais por um determinado período.

O projeto faz parte de um plano pessoal para uma jornada de aprendizado prático em desenvolvimento de software, com foco em programação Full Stack, banco de dados e boas práticas de Engenharia de Software.

## Funcionalidades planejadas:

- Cadastrar despesas com descrição, valor, data e categoria.
- Consultar o histórico de despesas.
- Editar e excluir despesas.
- Filtrar despesas por categoria.
- Calcular o total de despesas em um período selecionado.

## Tecnologias previstas:

- Python
- Flask
- JavaScript
- HTML
- CSS
- SQLite
- Git e GitHub

## Status do projeto:

Em desenvolvimento — fase inicial de planejamento e configuração.

Desenvolver autonomia na construção de aplicações, praticando análise de requisitos, modelagem de dados, validação de informações, organização do código, testes e documentação.
